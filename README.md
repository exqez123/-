# ИИ-агенты для Claude Code

В папке `.claude/agents/` лежат субагенты — специализированные помощники, которых Claude Code вызывает автоматически (по полю `description`) или по вашей просьбе.

| Агент | Что делает |
|---|---|
| `code-reviewer` | Проверяет изменения в коде и находит ошибки (только читает, ничего не меняет) |
| `debugger` | Ищет причину ошибки и исправляет её |
| `test-runner` | Запускает тесты, разбирает падения, пишет новые тесты |
| `docs-writer` | Пишет и обновляет документацию |

## Как пользоваться

Откройте этот репозиторий в Claude Code (CLI, десктоп или claude.ai/code) — агенты подключатся сами.

- Автоматически: Claude сам выберет агента, если задача подходит под его описание.
- Явно: напишите, например, «используй агента code-reviewer и проверь мои изменения».
- Изменить или добавить агента: отредактируйте файлы в `.claude/agents/` или попросите Claude («создай субагента, который ...»).

## Как добавить своего агента

Создайте файл `.claude/agents/<имя>.md`:

```markdown
---
name: my-agent
description: Когда использовать этого агента (по этому тексту Claude решает, вызывать ли его).
tools: Read, Grep, Glob, Bash   # необязательно; без поля — все инструменты
model: sonnet                    # необязательно: sonnet, opus, haiku или inherit
---

Системный промпт: роль агента, порядок работы, формат ответа.
```

Агенты в `.claude/agents/` действуют для этого проекта; личные агенты для всех проектов кладутся в `~/.claude/agents/`.
